# เส้นมันไก่ (Sen Man Gai) — เว็บไซต์แบรนด์พรีวิว

เว็บไซต์หลายหน้าสำหรับธุรกิจบะหมี่มันไก่ (บางแสน–อ่างศิลา, ชลบุรี) — สร้างเป็น static HTML/CSS/JS ล้วน ไม่มี build step ไม่ต้องใช้ backend

## โครงสร้างไฟล์
```
index.html      หน้าแรก
menu.html       เมนู
story.html      เรื่องราว / ผู้ก่อตั้ง
location.html   ทำเล
contact.html    ช่องทางติดตาม
assets/styles.css
assets/main.js
assets/favicon.svg
```

## ดูตัวอย่างในเครื่อง
เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์เล็กๆ:
```bash
npx serve .
```

## ขึ้น GitHub Pages
1. สร้าง repo ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ทั้งหมดขึ้น branch `main`
2. ไปที่ Settings → Pages → Source เลือก branch `main` และโฟลเดอร์ `/ (root)`
3. รอสักครู่แล้วลิงก์จะพร้อมใช้งานที่ `https://<username>.github.io/<repo>/`

```bash
git init
git add .
git commit -m "เว็บไซต์แบรนด์เส้นมันไก่"
git branch -M main
git remote add origin <URL ของ repo>
git push -u origin main
```

## สิ่งที่ควรทำต่อก่อนเปิดใช้งานจริง
- แทนที่ราคาประมาณการในหน้าเมนูด้วยราคาจริงเมื่อยืนยันสูตรและต้นทุนแล้ว
- เพิ่มรูปภาพอาหารจริงแทนไอคอน SVG เมื่อมีการถ่ายภาพเมนู (ตอนนี้ตั้งใจใช้กราฟิกล้วนเพราะยังไม่มีภาพจริง)
- เพิ่มไฟล์ `assets/og-image.png` ขนาด 1200×630px แล้วอ้างอิงด้วยแท็ก `<meta property="og:image">` ในทุกหน้า เพื่อให้ลิงก์แสดงภาพตัวอย่างสวยงามเวลาแชร์ใน LINE/Facebook
- เชื่อมช่องทาง Facebook/Instagram/Line จริงในหน้า `contact.html` (ตอนนี้ใส่ไว้เป็นสถานะ "เร็วๆ นี้" เพราะยังไม่ได้เปิดเพจจริง)
- อัปเดตพิกัด/ที่อยู่จริงในหน้า `location.html` เมื่อเซ็นสัญญาเช่าแล้ว

## ระบบดีไซน์
- สี: พื้นหลังชาร์โคลอุ่น + ทองน้ำมันไก่ (accent หลัก) + เขียวต้นหอม + แดงพริก (accent รอง)
- ฟอนต์: Kanit (หัวข้อ) + Noto Sans Thai (เนื้อหา)
- ลายเซ็นแบรนด์ (motif): "หยดมัน" เส้นบะหมี่ม้วนเป็นก้นหอยจนจบที่จุดหยดน้ำมันไก่ — ใช้ซ้ำในโลโก้ ตัวคั่นหัวข้อ ปุ่ม และท้ายเว็บ
